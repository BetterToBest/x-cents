# X-Cents

A standalone site presenting **CurrentSea X-Change (X-Cents)**, a citizen-led monetary framework that lets communities reassign value to the coins and bills they already hold.

**Live site:** https://bettertobest.github.io/x-cents/

## What's here

- `index.html`: the whole site in one self-contained file (styles and scripts included; only Google Fonts load externally).

## Linking to a section

Other pages, articles and papers can link straight to any part of the site:

- `#idea` (the five principles)
- `#wrap` (Wrap Your Bills)
- `#power` (The Power of 1)
- `#wheel` (the Saturday wheel)
- `#why` (why now)
- `#rollout` (how a town could begin)
- `#portal` (the Citizens Internet Portal)
- `#research` (the paper and details)

Example: `https://bettertobest.github.io/x-cents/#portal`
